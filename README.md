# 🚦 Smart Traffic Monitoring System

An AI-based system for real-time traffic violation detection using YOLOv8.  
The system detects helmet violations, tracks objects, logs violations with location, saves evidence images, and displays results on an interactive dashboard.

---

## 📌 Features

- 🔍 Real-time object detection using YOLOv8  
- 🪖 Helmet violation detection  
- 🧠 Object tracking with unique IDs  
- 📸 Automatic evidence image capture  
- 📊 Interactive Streamlit dashboard  
- 🗺️ Map-based violation visualization  
- 🔔 Alert system for violations  
- 📝 Clean logging system  

---

## 🛠️ Tech Stack

- **Language:** Python  
- **Libraries:** OpenCV, Ultralytics (YOLOv8), Pandas  
- **Dashboard:** Streamlit  
- **Model:** YOLOv8 (custom-trained)
